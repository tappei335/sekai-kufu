プライバシーポリシー

最終更新日: 2026年11月21日

「世界の工夫図鑑 管理ツール」(以下「本ツール」)は、YouTube チャンネル「世界の工夫図鑑」の運営者が、自分のチャンネルを管理するためだけに使う個人用のツールです。運営者以外の人は利用しません。

YouTube API サービスの利用

本ツールは YouTube API サービスを使っています。本ツールを使うことで、YouTube 利用規約に同意したことになります。Google によるデータの扱いは、Google プライバシーポリシーをご覧ください。

取得する情報と使い道

運営者が自分の Google アカウントで許可した範囲で、次の情報を扱います。

  • 運営者のチャンネルの名前、登録者数、動画数(接続先の確認のため)
  • 運営者が投稿する動画、題名、説明、タグ、字幕(運営者のチャンネルへ投稿するため)
  • 投稿した動画の公開状態、再生数、高評価数、コメント数、視聴の分析の数値(動画の改善のため)

これらは運営者が管理するサーバーにだけ保存し、第三者に提供、販売、共有することはありません。他のユーザーの情報は取得しません。

認証情報の保存

Google から受け取ったアクセストークンは、運営者のサーバーに保存し、外部には送りません。

許可の取り消しと削除

本ツールへの許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。取り消すか、本ツールの「接続を解除」を行うと、保存していたトークンは削除されます。

このポリシーの変更

内容を変えるときは、このページを更新し、最終更新日を改めます。
